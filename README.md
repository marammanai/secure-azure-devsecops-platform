# secure-azure-devsecops-platform
Secure Azure infrastructure automation and DevSecOps implementation using Terraform, GitHub Actions and security scanning.

## Project Overview

This project demonstrates a secure DevSecOps platform on Microsoft Azure.

It combines Infrastructure as Code, CI/CD automation, container security, and Kubernetes deployment.

## Objectives

- Automate Azure infrastructure with Terraform.
- Build CI/CD pipelines with Jenkins.
- Scan infrastructure and containers for vulnerabilities.
- Deploy applications using Docker and Kubernetes.
- Apply DevSecOps security best practices.

## Technologies

- Microsoft Azure
- Terraform
- Jenkins
- Docker
- Kubernetes
- Git
- Checkov
- Trivy
