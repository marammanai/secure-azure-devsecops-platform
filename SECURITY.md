# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to the project maintainer.

Do not publish sensitive security details in public issues.

## Security Practices

This project follows these security practices:

- Never commit passwords, tokens, or secrets.
- Scan Docker images with Trivy.
- Scan Terraform configurations with Checkov.
- Use Azure Key Vault for secret management.
- Review dependencies and security updates.
